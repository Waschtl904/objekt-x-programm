# 1. Der ungekürzte Mark-Field ist terminalunabhaengig fuer einen alten Source-Vektor

Fuer ein kompakt getragenes altes `f in L^2(-R,R)` setze seine Nullfortsetzung auf die reelle Linie mit `E_Rf` an.

Definiere punktweise das ungekürzte finite-adische Feld

```math
\boxed{
Z_f(u)
:=
\sum_p\sum_{k\ge1}
\sqrt{\log p}\,p^{-k/4}
D_{k\log p}E_Rf(u)\otimes\eta_{p,k}.
}
```

Fuer jedes feste `u` ist die Summe effektiv endlich: fuer hinreichend grosse `k log p` liegen beide verschobenen Argumente ausserhalb des festen Traegers von `E_Rf`.

Wird `f` nach `(-S,S)` nullfortgesetzt, gilt als Funktion auf der ganzen reellen Linie

```math
E_SE_{R,S}f=E_Rf.
```

Daher ist **dasselbe** Feld `Z_f(u)` fuer alle spaeteren Terminalradien `S>R` wirksam.
