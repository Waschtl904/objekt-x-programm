``````````text
# PR #116 — ATTACK THIS

This document lists the places where a hostile auditor should try hardest to break the frozen snapshot.

The goal is not to defend the narrative. The goal is to find the first invalid inference, hidden domain assumption, wrong normalization, or uncertified numerical dependency.

## 1. Range theorem / operator domain

Attack

```math
\mathscr D_{NP,a}=L_{1/2}C_c^\infty(-a,a).
```

Check independently:

- both inclusions;
- the whole-line Green normalization;
- endpoint/support leakage;
- whether the claimed inverse maps back into `C_c^∞(-a,a)` exactly;
- uniqueness.

Then separately attack the shorthand

```math
\mathcal N_a=(z^2+1/4)PW_a.
```

Do **not** accept this as an equality of closed Hilbert spaces unless the multiplication-operator domain is stated and the `L^2` condition is proved. The review package intentionally avoids relying on this unrestricted formulation.

## 3. Gamma / critical-half normalization

Audit every factor of `2` in

```math
\frac{e^{-t/2}}{1-e^{-2t}}
=\sum_{m\ge0}e^{-(2m+1/2)t}.

```math
\frac1{2μ}e^{-μ|x-y|}

Do not treat recurrence of `1/2` as a theorem by itself; only exact operator identities count.
``````````
