``````````text
# 3. Der entscheidende Rest-Inversenwert ist unabhaengig von K

```math

```math

```math
\nu^*(R_K-\nu\nu^*)^{-1}\nu

```math

In der zweiten Gleichung ist der durch `y_1` erzeugte Anteil bereits exakt `q^2`, daher `y_2=0`. Induktiv folgt

# 4. Mehrere Prime-Aeste addieren wie parallele Root-Kanaele

Sei nun `P` eine endliche Menge von Primzahlen und auf jedem Ast `p` mindestens ein Knoten gewaehlt. Die Innovationsraeume verschiedener Aeste sind orthogonal. Deshalb ist der globale Rest-Gram `D` blockdiagonal, waehrend alle Aeste denselben Root teilen.

Fuer die globale Root-Spalte `alpha` gilt daher

```math
\boxed{
\alpha^*D^{-1}\alpha
=\sum_{p\in P}\frac1{p-1}
=:S_P.
}
```

Der volle Gram ist

```math
C=D+\alpha\alpha^*.
```

Sherman--Morrison liefert

```math
C^{-1}
=D^{-1}
-\frac{D^{-1}\alpha\alpha^*D^{-1}}{1+S_P}.
```

Daraus

```math
\boxed{
\alpha^*C^{-1}\alpha
=\frac{S_P}{1+S_P}.
}
```

# 7. Radius-Filtration

Fuer ein Fenster `a` sind genau die Primzahlen

```math
p\le e^{2a}
```

mit mindestens einer aktiven Prime-Power vorhanden. Daher besitzt der P11-Tree-Root auf der aktiven Kanalmenge die exakte Leverage

```math
\boxed{
\lambda_{root}(a)
=
\frac{S(a)}{1+S(a)},
\qquad
S(a)=\sum_{p\le e^{2a}}\frac1{p-1}.
}
```

Sie springt nur beim Eintritt einer **neuen Primzahl**, nicht beim Eintritt von `p^2,p^3,...`.

Klassisch folgt aus der Mertens-Asymptotik fuer Primzahlen

```math
S(a)=\log(2a)+O(1)
```

fuer grosse `a`, also nur sehr langsame Annäherung `lambda_root(a)->1`. Dieser asymptotische Zusatz ist fuer den exakten endlichen Satz nicht erforderlich.

# 8. No-Go: der eine P11-Root ist nicht die COMMON-JUMP-Schwelle

Die COMMON-JUMP-Schwelle enthaelt

```math
\Gamma_a^{prime}
=2\sum_{\log n\le2a}\frac{\Lambda(n)}{\sqrt n}.
```

Wenn ein hoeheres `p^k`, `k>=2`, den Cutoff `2a` ueberschreitet, steigt diese Schwelle strikt um

```math
2\frac{\log p}{p^{k/2}}>0.
```

Die P11-Root-Leverage bleibt beim selben Ereignis aber **exakt konstant**, weil sich die zugrunde liegende Primmenge nicht aendert.

Da verschiedene Prime-Power-Schwellen `p^k` mit `k>=2` nicht mit dem Eintritt einer neuen Primzahl identisch sind, kann man den Radius lokal ueber einen solchen Schwellenwert bewegen, ohne eine neue Primart hinzuzunehmen.

Daher ist jede Identifikation

```text
COMMON-JUMP prime threshold
=
Skalar, der nur von der Leverage des einen vorhandenen P11-Rootvektors abhaengt
```

unmoeglich.

Das bedeutet **nicht**, dass die P11-Tree-Geometrie irrelevant ist. Es bedeutet nur:

> Der gemeinsame Root allein ist zu arm. Ein erfolgreicher Forward-Mechanismus muss zusaetzlich die Ast-Innovationen, die raeumlichen `K_t`-Inzidenzen, Gamma-/Boundary-Geometrie oder eine echte Kopplung zwischen diesen Strukturen verwenden.
``````````
