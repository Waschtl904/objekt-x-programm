# P11 Audit — Prime-only AR(1) cell sampling normal form

**Datum:** 15. September 2026

## 0. Result

Let `v` be smooth, compactly supported, and NULLPOL. For `h>0` put

```math
q=e^{-h/2},
\qquad
B_h=\sqrt{\frac{hq(1+q)}{1-q}}(T_h-I)(I-qT_h)^{-1},
```

and define the centered cell response

```math
\boxed{
C_v(h)
:=\|B_hv\|_2^2
-2\frac{hq}{1-q}\|v\|_2^2.
}
```

If `supp(v) subset [-a,a]`, then `C_v(h)=0` for `h>2a`.

With

```math
\rho(h)=\sum_{m\ge1}\frac{h^{m-1}}{m!\zeta(m+1)},
\qquad
\mu_m=2m+1/2,
```

and

```math
E_{Gamma,>=1}(v)
=\sum_{m\ge1}\frac2{\mu_m}
\left\|\partial(\partial+\mu_m)^{-1}v\right\|_2^2,
```

the NULLPOL Weil form is exactly

```math
\boxed{
Q_W(v)
=
\sum_p C_v(\log p)
-\frac12\int_0^\infty\rho(h)C_v(h)dh
+E_{Gamma,>=1}(v)
-(\kappa_*-4)\|v\|_2^2.
}
```

The exterior sum is now over **primes only**. Every prime-power tower has been compressed into the one-state AR(1)/Euler cell `B_logp`.

Status: identity `✓[M]`; positivity `?[O]`; no novelty/RH claim.

## 1. Centered cell as a Lambert transform

Let

```math
F_v(t)=f_v(t)+f_v(-t),
\qquad f_v=v*\widetilde v.
```

The prime-tower compression gives

```math
\|B_hv\|^2
=\sum_{k\ge1}h e^{-kh/2}\|K_{kh}v\|^2.
```

Since

```math
\|K_tv\|^2=2\|v\|^2-F_v(t),
```

we obtain

```math
\boxed{
C_v(h)
=-\sum_{k\ge1}h e^{-kh/2}F_v(kh).
}
```

For `h>2a`, all `kh` lie outside the autocorrelation support and `C_v(h)=0`.

## 2. Continuum cell average

The positive continuum Euler-cell audit proved

```math
\int_0^\infty\rho(h)\nu_h(dt)dh
=(e^{t/2}-e^{-t/2})dt,
```

where

```math
\nu_h=\sum_{k\ge1}h e^{-kh/2}\delta_{kh}.
```

Therefore

```math
I_\rho(v)
:=\int_0^\infty\rho(h)C_v(h)dh
=-\int_0^\infty F_v(t)(e^{t/2}-e^{-t/2})dt.
```

For NULLPOL the pole moments vanish, hence

```math
\int_0^\infty F_v(t)(e^{t/2}+e^{-t/2})dt=0.
```

Writing

```math
B_0(v):=\int_0^\infty e^{-t/2}F_v(t)dt,
```

we get

```math
\boxed{I_\rho(v)=2B_0(v).}
```

The Gamma ground-mode energy is

```math
E_{Gamma,0}(v)
=\int_0^\infty e^{-t/2}\|K_tv\|^2dt
=4\|v\|^2-B_0(v),
```

so

```math
\boxed{
E_{Gamma,0}(v)
=4\|v\|^2-\frac12 I_\rho(v).
}
```

## 4. No information loss: Moebius inversion

Define

```math
L_v(h):=-\frac{C_v(h)}h
=\sum_{k\ge1}e^{-kh/2}F_v(kh).
```

Because `F_v` is compactly supported, every dilation sum below is finite at fixed `h`. Ordinary Moebius inversion gives

```math
\boxed{
e^{-h/2}F_v(h)
=\sum_{k\ge1}\mu(k)L_v(kh).
}
```

Equivalently,

```math
F_v(h)
=-e^{h/2}\sum_{k\ge1}\frac{\mu(k)}{kh}C_v(kh).
```

Thus the one-cell response `C_v(h)` is an invertible recoding of the original autocorrelation data; the prime-only normal form does not discard the prime-power information.
