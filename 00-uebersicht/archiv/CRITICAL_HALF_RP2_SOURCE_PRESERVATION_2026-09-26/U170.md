# 1. Der P11-Feshbachterm ist ein echter positiver Schur-Komplement

Die Operatoren seien

```math
H_R:\mathscr H_R\to\mathscr H_R,
\qquad
R_R:\mathscr H_R\to\mathscr K_R^{rest}.
```

Betrachte auf

```math
\mathscr H_R\oplus\mathscr K_R^{rest}
```

die Blockmatrix

```math
\boxed{
\mathcal G_R
=
\begin{pmatrix}
H_RH_R^*&H_RR_R^*\\
R_RH_R^*&I+R_RR_R^*
\end{pmatrix}.
}
```

Sie besitzt die manifest positive Faktorisierung

```math
\mathcal G_R
=
\begin{pmatrix}H_R\\R_R\end{pmatrix}
\begin{pmatrix}H_R^*&R_R^*\end{pmatrix}
+
\begin{pmatrix}0&0\\0&I\end{pmatrix}
\succeq0.
```

Der untere Block erfuellt

```math
I+R_RR_R^*\succeq I.
```

Sein Schur-Komplement ist

```math
H_RH_R^*
-H_RR_R^*(I+R_RR_R^*)^{-1}R_RH_R^*.
```

Mit der Woodbury-Identitaet

```math
I-R_R^*(I+R_RR_R^*)^{-1}R_R
=(I+R_R^*R_R)^{-1}
```

folgt exakt

```math
\boxed{
\operatorname{Schur}_{rest}(\mathcal G_R)
=H_R(I+R_R^*R_R)^{-1}H_R^*
=\Sigma_R.
}
```

Dies ist ein **nichtzirkulaerer Forward-Schur-Schritt**: `H_R`, `R_R` und der Identitaetsblock sind vor jeder Zielpositivitaet explizit definiert.
