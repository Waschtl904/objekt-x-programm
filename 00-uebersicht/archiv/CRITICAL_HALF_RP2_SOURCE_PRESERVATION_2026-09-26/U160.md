# 2. Orientierter Green-Transfer

## Satz 2.1 — links nach rechts

Seien `f,g in C_c^infty(R)` und

```math
\sup\operatorname{supp}f
<
\inf\operatorname{supp}g.
```

Dann ist fuer jedes `x in supp f` und `y in supp g` stets `x<y`, also

```math
e^{-|x-y|/2}
=e^{-(y-x)/2}
=e^{x/2}e^{-y/2}.
```

Daher

```math
\begin{aligned}
\langle f,Gg\rangle
&=
\int f(x)
\overline{\int e^{-(y-x)/2}g(y)dy}
\,dx\\
&=
\left(\int e^{x/2}f(x)dx\right)
\overline{\left(\int e^{-y/2}g(y)dy\right)}.
\end{aligned}
```

Somit

```math
\boxed{
\langle f,Gg\rangle
=E_+(f)\overline{E_-(g)}.
}
```

## Satz 2.2 — rechts nach links

Ist umgekehrt

```math
\sup\operatorname{supp}g
<
\inf\operatorname{supp}f,
```

so `x>y` und

```math
e^{-|x-y|/2}
=e^{-x/2}e^{y/2}.
```

Daher

```math
\boxed{
\langle f,Gg\rangle
=E_-(f)\overline{E_+(g)}.
}
```

Diese beiden Formeln sind exakte algebraische Folgen des Green-Kerns; keine explizite Formel, keine Zeta-Nullstelle und keine Positivitaetsannahme wird verwendet.
