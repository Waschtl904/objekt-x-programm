# P11 Audit — Every Euler cell is a contraction of the Gamma ground

**Datum:** 16. September 2026  
**Branch:** `research/critical-half-green-tree-bridge-2026-09-13`  
**Registry:** unveraendert.  
**Nonclaim:** kein RH-/Object-X-Beweis; keine globale Prime/Continuum-Kopplung.

## 0. Result

For `h>0`, `q=e^{-h/2}`, let

```math
A_h
:=\sum_{k\ge1}h e^{-kh/2}K_{kh}^*K_{kh}
=B_h^*B_h,
```

where

```math
B_h
=\sqrt{\frac{h q(1+q)}{1-q}}
(T_h-I)(I-qT_h)^{-1}.
```

Let the Gamma ground operator be

```math
A_0
:=\int_0^\infty e^{-t/2}K_t^*K_tdt
=4D^2(D^2+1/4)^{-1}.
```

Then for every `h>0`,

```math
\boxed{0\preceq A_h\preceq A_0.}
```

Thus the strong `h->0` limit from the earlier audit is actually accompanied by a global Loewner domination valid at every positive scale.

Equivalently there is a canonical commuting contraction `C_h` such that

```math
\boxed{A_h^{1/2}=C_hA_0^{1/2},\qquad \|C_h\|\le1.}
```

At the transfer-function level one may choose

```math
b_h(s)
=\sqrt{\frac{h q(1+q)}{1-q}}
\frac{1-e^{-hs}}{1-qe^{-hs}},
\qquad
b_0(s)=\frac{2s}{s+1/2},
```

and

```math
\boxed{\Phi_h(s):=\frac{b_h(s)}{b_0(s)}.}
```

The singularity at `s=0` is removable, all poles of `Phi_h` lie in `Re s<0`, and the boundary inequality proved below gives

```math
|\Phi_h(i\omega)|\le1.
```

Hence `Phi_h` is a Schur transfer on the right half-plane. Each complete Euler/AR(1) cell therefore has a coefficient-free passive relative realization with respect to the Gamma ground port.

This does **not** solve the global storage problem: the orthogonal row of all prime contractions is unbounded. Thus the remaining difficulty is genuinely the non-diagonal relative scale coupling.

# 1. Exact multipliers

The earlier `h=0` audit gives

```math
A_h=a_h(D),
\qquad
a_h(z)
=h\left[\frac{1+q}{1-q}-P_q(hz)\right],
```

where

```math
P_q(\theta)
=\frac{1-q^2}{1-2q\cos\theta+q^2}.
```

Also

```math
a_0(z)=\frac{4z^2}{z^2+1/4}.
```

Set

```math
x=\frac h4,
\qquad
y=\frac{hz}{2}.
```

Since `q=e^{-2x}`,

```math
\frac{1+q}{1-q}=\coth x,
```

and

```math
P_q(2y)
=\frac{\sinh(2x)}{\cosh(2x)-\cos(2y)}.
```

Using

```math
\cosh(2x)-\cos(2y)
=2(\sinh^2x+\sin^2y),
```

one obtains

```math
\boxed{
a_h(z)
=4x\coth x\,
\frac{\sin^2y}{\sinh^2x+\sin^2y},
}
```

while

```math
\boxed{
a_0(z)=\frac{4y^2}{x^2+y^2}.}
```

Thus the desired operator order is the scalar inequality `a_h(z)<=a_0(z)`.

# 2. Circular auxiliary inequality

For every real `y`,

```math
\boxed{\frac{y^2}{\sin^2y}\ge1+\frac{y^2}{3}}
```

with the usual interpretation at zeros of `sin y`.

Equivalently

```math
\sin^2y\le\frac{3y^2}{3+y^2}.
```

For `y^2>=3/2` the right side is at least one, so the estimate is immediate.

For `0<=y^2<=3/2`, alternating Taylor gives

```math
\frac{\sin y}{y}
\le1-\frac{y^2}{6}+\frac{y^4}{120}.
```

Put `t=y^2`. Direct algebra gives

```math
1-
\left(1-\frac t6+\frac{t^2}{120}\right)^2
\left(1+\frac t3\right)
=
\frac{t^2(2880-520t+37t^2-t^3)}{43200}>0
```

on `0<=t<=3/2`. This proves the auxiliary inequality globally.

# 3. Two hyperbolic inequalities

Put

```math
a(x):=\frac{\tanh x}{x}.
```

We need two elementary estimates.

## 3.1 Lazarevic-type inequality

```math
\boxed{a(x)\sinh^2x\ge x^2.}
```

This is equivalent to

```math
\left(\frac{\sinh x}{x}\right)^3\ge\cosh x.
```

For a self-contained proof define

```math
F(x)=3\log\frac{\sinh x}{x}-\log\cosh x.
```

Then

```math
F'(x)=3\coth x-\frac3x-\tanh x.
```

Multiplying by `x sinh x cosh x>0` reduces the sign to

```math
G(x)=x(3+2\sinh^2x)-3\sinh x\cosh x.
```

Now

```math
G'(x)=4\sinh x\,(x\cosh x-\sinh x)\ge0,
```

because `(x cosh x-sinh x)'=x sinh x>=0`. Since `G(0)=0`, `F'>=0`; and `F(0)=0`, proving the claim.

## 3.2 Coefficient inequality

```math
\boxed{a(x)-1+\frac{a(x)\sinh^2x}{3}\ge0.}
```

This is equivalent to

```math
\tanh x\,(3+\sinh^2x)\ge3x.
```

For

```math
H(x)=\tanh x\,(3+\sinh^2x)-3x
```

one gets exactly

```math
H'(x)=\frac{2\sinh^4x}{\cosh^2x}\ge0,
```

and `H(0)=0`.

# 4. Loewner domination

For `sin y !=0`, the inequality `a_h<=a_0` is equivalent, after taking reciprocals, to

```math
\frac{\tanh x}{x}
\left(1+\frac{\sinh^2x}{\sin^2y}\right)
\ge
1+\frac{x^2}{y^2}.
```

Multiplying by `y^2` gives the left-minus-right expression

```math
y^2(a-1)
+a\sinh^2x\frac{y^2}{\sin^2y}
-x^2.
```

By Section 2 this is at least

```math
\bigl(a\sinh^2x-x^2\bigr)
+y^2\left(a-1+\frac{a\sinh^2x}{3}\right),
```

which is nonnegative by Sections 3.1 and 3.2.

At zeros of `sin y`, `a_h=0`; at `y=0` the same conclusion follows by continuity. Hence

```math
\boxed{0\le a_h(z)\le a_0(z)\quad\text{for all real }z.}
```

Functional calculus yields

```math
\boxed{0\preceq A_h\preceq A_0.}
```

The previous aliasing result remains sharp: at `z=2pi n/h`, `a_h(z)=0` while `a_0(z)->4`, hence

```math
\|A_0-A_h\|=4.
```

# 5. Canonical local Schur factor

On the imaginary boundary,

```math
|b_h(i\omega)|^2=a_h(\omega),
\qquad
|b_0(i\omega)|^2=a_0(\omega).
```

Thus

```math
|\Phi_h(i\omega)|\le1.
```

The zeros at `s=0` cancel. The poles from `1-qe^{-hs}` satisfy

```math
s=-\frac12+\frac{2\pi i n}{h}
```

(up to the sign convention for the Fourier/Laplace exponential), hence lie strictly in the left half-plane. The transfer is bounded in the right half-plane and has finite limit at infinity. By the maximum principle,

```math
\boxed{\|\Phi_h\|_{H^\infty(\Re s>0)}\le1.}
```

Therefore each local Euler cell is passively subordinate to the Gamma ground cell.

A canonical Julia colligation is supplied by the commuting contraction

```math
C_h=\Phi_h(D)
```

(or equivalently the positive multiplier `sqrt(a_h/a_0)` if only the energy factor is needed):

```math
\mathcal U_h=
\begin{pmatrix}
C_h & (I-C_h^*C_h)^{1/2}\\
(I-C_hC_h^*)^{1/2} & -C_h^*
\end{pmatrix}.
```

No Weil positivity or zero information is used in this local construction.

# 6. Why the local PASS does not globalize orthogonally

Let

```math
r_h(0):=\lim_{z\to0}\frac{a_h(z)}{a_0(z)}.
```

From the formulas above,

```math
\boxed{
r_h(0)
=\frac{x^3\cosh x}{\sinh^3x},
\qquad x=h/4.
}
```

At a prime scale `h=log p`,

```math
r_{\log p}(0)
\sim\frac{(\log p)^3}{16\sqrt p}.
```

Hence

```math
\sum_p r_{\log p}(0)=\infty.
```

Indeed for large primes this term dominates a positive constant multiple of `1/p`, and Euler's prime harmonic series diverges.

Consequently the naive orthogonal row

```math
f\mapsto(C_{\log p}f)_p
```

from a single Gamma-ground port to all prime outputs is unbounded. Equivalently, local passive subordination does not furnish a global orthogonal direct-sum storage.

This sharpens the remaining gate:

```text
local relative storage: solved exactly;
global relative scale storage: still open and necessarily non-diagonal/renormalized.
```

The Riemann-R continuum or an overlap-cone scale coupling is therefore not optional if this branch is to produce an Object-X mechanism.
