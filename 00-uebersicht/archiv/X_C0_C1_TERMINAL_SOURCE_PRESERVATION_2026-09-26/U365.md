``````````text
# 1. Prime-base statt Prime-Power als sichere lokale Zelle

Fuer eine Primzahl `p` setze

```math
h_p=\log p,
\qquad q_p=p^{-1/2}.
```

Die sichere Root-Quadratmasse des **vollstaendigen** p-Towers ist

```math
\boxed{
a_p
:=\sum_{k\ge1}(\log p)p^{-k}
=\frac{\log p}{p-1}.
}
```

Dies ist die DC-Masse der lokalen sicheren Euler-/AR(1)-Zelle

```math
\boxed{
m_p(s)
:=\sum_{k\ge1}(\log p)p^{-k(1+s)}
=\frac{\log p}{p^{1+s}-1},
\qquad \Re s>0.
}
```

und

```math
\sum_p m_p(s)
=-\frac{\zeta'}{\zeta}(1+s).
```

Damit ist fuer einen globalen `cancel-first`-Transport eine Zelle pro Primzahl natuerlicher als eine unabhaengige Zelle pro Primzahlpotenz: die interne geometrische p-Power-Reihe bleibt in `m_p` erhalten.

### Firewall

`a_p` ist eine Root-/Transfermasse. Sie ist **nicht** die volle gewichtete P11-Hubnorm eines Quellenvektors und nicht die Weilenergie. Ein Quellenoperator muss weiterhin ueber die typisierten X-C0-Memory-/Jump-Ports gebaut werden.

# 2. Monotone Prime-base-Transportzellen

Ordne die Primzahlen

```math
p_1<p_2<\cdots
```

und setze

```math
s_0=\gamma,
\qquad
s_j=\gamma+\sum_{i\le j}a_{p_i},
\qquad
I_{p_j}=[s_{j-1},s_j).
```

Dann

```math
|I_p|=a_p.
```

Mit dem klassischen, unbedingten PNT-Fehler folgt

```math
\sum_{p\le x}\frac{\log p}{p-1}
=\log x-\gamma
+O\!\left((1+\sqrt{\log x})e^{-c\sqrt{\log x}}\right)
```

fuer ein `c>0` (eine schwaechere quantitative Form reicht). Der konstante Term ist derselbe `-gamma`, weil

```math
\sum_{p\le x}\frac{\log p}{p-1}
-
\sum_{p^k\le x}\frac{\log p}{p^k}
\longrightarrow0,
```

waehrend

```math
\sum_{n\le x}\frac{\Lambda(n)}n
=\log x-\gamma+o(1).
```

Daher

```math
\boxed{s_j-\log p_j\longrightarrow0.}
```

Schreibe

```math
\delta_p:=\sup_{L\in I_p}|L-h_p|.
```

Dieselbe PNT-Abschatzung und partielle Summation liefern

```math
\boxed{\sum_p a_p\delta_p<\infty.}
```

Diese quantitative Summierbarkeit benoetigt keine RH-Information.

**Status:** algebraische Zellidentitaet `✓[M]`; quantitative Lokalisierung `✓[K/M]` unter dem klassischen PNT-Eingang.

# 3. Exakte sichere relative Transferzerlegung

Da die Intervalle `I_p` zusammen mit `[0,gamma)` die positive Halbgerade partitionieren, gilt fuer `Re s>0` exakt

```math
\boxed{
\gamma-\frac1s-\frac{\zeta'}{\zeta}(1+s)
=
\gamma-\int_0^\gamma e^{-sL}dL
+
\sum_p
\left[
 m_p(s)-\int_{I_p}e^{-sL}dL
\right].
}
```

Die Zellreihe besitzt fuer jedes feste `s` mit `Re s>=0` eine direkte absolut konvergente Randdarstellung.

Dazu zerlege

```math
m_p(s)-\int_{I_p}e^{-sL}dL
=
\left[m_p(s)-a_pe^{-sh_p}\right]
+
\int_{I_p}\left(e^{-sh_p}-e^{-sL}\right)dL.
```

Der interne Towerfehler ist

```math
\boxed{
m_p(s)-a_pe^{-sh_p}
=
\frac{(\log p)p^{-1-s}\,p^{-1}(p^{-s}-1)}
{(1-p^{-1-s})(1-p^{-1})}.
}
```

Fuer festes `s`, `Re s>=0`, ist sein Betrag `O_s((log p)/p^2)` und daher primweise absolut summierbar.

Der Transportfehler erfuellt

```math
\left|
\int_{I_p}(e^{-sh_p}-e^{-sL})dL
\right|
\le |s|a_p\delta_p,
```

also ist auch seine Primzahlsumme absolut konvergent.

Damit ist die sichere Prime/Continuum-Relativstufe nun exakt auf dieselbe **eine-Zelle-pro-Primzahl**-Organisation gebracht, die auch zur lokalen Euler-/AR(1)-Dynamik passt.

### Wichtige Grenze

Diese Zerlegung ist noch kein positiver C1-Readout. Sie konstruiert eine stabile relative Transferstufe und fixiert die richtige lokale Organisation; die Critical-half-Ausgabe bleibt der offene Schritt.

# 5. Raw-memory 2x2 transport fails the fixed witness

Fuer `p=2` ist

```math
a_2=\frac{\log2}{2-1}=\ell,
\qquad
I_2=[\gamma,\gamma+\ell).
```

Betrachte fuer ein beliebiges `L in I_2` die zwei rohen Memory-Koordinaten

```text
H(.,ell),  H(.,L).
```

Die vier moeglichen gemischten Basisprodukte zwischen `f` und `g` haben Mittelpunktabstaende

```text
< H_f(.,ell), H_g(.,ell) > :  ell
< H_f(.,ell), H_g(.,L)   > :  L
< H_f(.,L),   H_g(.,ell) > :  2 ell - L
< H_f(.,L),   H_g(.,L)   > :  ell.
```

Auf `I_2` gilt

```math
L\ge\gamma>2\varepsilon,
```

und

```math
2\ell-L\ge\ell-\gamma>2\varepsilon.
```

Fuer die letzte numerische Trennung genuegen etwa die elementaren rationalen Schranken

```text
log 2 > 0.69,
gamma < 0.58,
```

also `ell-gamma>0.11>0.02=2 epsilon`.

Daher sind **alle vier** Skalarprodukte exakt null:

```math
\boxed{
\langle H_f(\cdot,r),H_g(\cdot,s)\rangle_{L^2_x}=0
\quad
(r,s\in\{\ell,L\},\ L\in I_2).
}
```

Folglich gilt fuer **jede** messbare `2x2`-Matrixkopplung `M(L)`, die nur diese beiden rohen Memory-Koordinaten bei gleichem x mischt,

```math
\boxed{
\int_{I_2}
\left\langle
M(L)
\binom{H_f(\cdot,\ell)}{H_f(\cdot,L)},
M(L)
\binom{H_g(\cdot,\ell)}{H_g(\cdot,L)}
\right\rangle dL
=0.
}
```

Dasselbe gilt mit einer positiven Matrixmetrik statt `M^*M`.

Damit ist die naheliegendste Klasse

```text
equal-mass 2x2 cell + raw memory evaluation + no x/jump incidence
```

auf dem bereits fixierten Prime-2-Zeugen rigoros ausgeschlossen.

**Status:** `×[M]` fuer genau diese Klasse.

Also

```math
\boxed{
\left\langle
\mathcal P_{2,1}T^0_1f,
\mathcal P_{2,1}T^0_1g
``````````
