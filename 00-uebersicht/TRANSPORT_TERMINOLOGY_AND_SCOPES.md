# Transport terminology and scopes

This file separates the historical P11 fixed-pair result from the open C1 continuation problem. It is a scope ledger, not a theorem proof.

| Term | Meaning | Status |
|---|---|---|
| Source transport | Exact zero extension J_{a,b}. | CLOSED on the fixed-horizon system |
| Form naturality | q_b(J_{a,b}u,J_{a,b}v)=q_a(u,v). | CLOSED on the fixed-horizon system |

## Registry binding

The only promoted historical Strong-Terminal identifier is P11-FIXED-PAIR-STRONG-TERMINAL. It means:

- fixed pair 0<R<S<infinity;
- original odd P11 graph space;
- strong vectorwise operator topology on individual vectors;
- no uniformity in R,S;
- no operator-norm convergence;
- no rate;
- no assertion about the new C1 horizon-change problem.

The global C1 continuation front remains UNRESTRICTED-HORIZON-AND-PROFILE-CONTINUATION. The P11 fixed-pair result is a reusable comparison theorem and does not close that front.
