# C1d terminal positive completion

Fixed-horizon theorem for the coupled spectral C1 candidate.

The theorem uses the promoted strict terminal contraction to define the single
operator
\[
\Delta_1=(I-R_1^*R_1)^{1/2}
\]
on \(H_1\), then
\[
T_{X,a}=\Delta_1 I_{a,1}T_a.
\]

It proves, for the established C1 range \(B\le a\le b\le1\),
\[
q_a(u,v)=\langle T_{X,a}u,T_{X,a}v\rangle,
\qquad
T_{X,b}J_{a,b}=T_{X,a}.
\]

No local square-root intertwining is assumed. No statement beyond terminal
horizon \(1\), no global Object X, no global Weil positivity and no RH claim
is made.
