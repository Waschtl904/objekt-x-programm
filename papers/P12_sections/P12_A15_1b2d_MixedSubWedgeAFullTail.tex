\section{A15.1b2d: partial results on the full Sub-wedge~A}
\label{sec:p12-b2d}

The full Sub-wedge~A statement $e/2 \le R < d/2$, $T < S < T_{0}$,
$\ker L = 0$ remains open
(Open Problem~\ref{open:p12-subwedgeA-open}).  This module
records two proven local kills that carve out sub-regions of the
b2d parameter space, together with the residual open front.

\subsection{Setup and region-splitting}

For $e/2 \le R < d/2$, $R < \sigma < \varepsilon < \varepsilon_{\max}$
with $\varepsilon_{\max} = \tfrac12 \log(5/4)$, the defect strip
$(R, \sigma)$ splits into three geometric sub-regions:
\begin{itemize}
\item \textbf{b2d-upper}: $x \in (d - R, \sigma)$, nonempty iff
  $\sigma > d - R$ (requires $R > d - \varepsilon_{\max}$).
  Here $h(d - x) = 0$ by support ($d - x < R$).
\item \textbf{b2d-core-both}: $x \in (d - \sigma, d - R)$,
  nonempty iff $\sigma > d - R$.  Here both $h(x)$ and $h(d - x)$
  are live lower-support values \emph{and} $H(x), H(d - x)$ are
  live tail values.
\item \textbf{b2d-core-single}: $x \in (R, d - \sigma)$.  Here
  $h(d - x)$ live but $H(d - x) = 0$ by support ($d - x > \sigma$).
\end{itemize}

\subsection{b2d-upper local kill}

See Corollary~\ref{cor:p12-b2d-upper-local} in the b2c module
(\S\ref{sec:p12-b2d-upper}).  The 13-source certificate of
Theorem~\ref{thm:p12-b2c} transfers verbatim under the support
conditions available at $x > d - R$.

\subsection{b2d-core-single: horizon-legal 19-source slice}
\label{sec:p12-b2d-core-single-slice}

We now close a slice of b2d-core-single by a genuine
$19 \times 19$ typed elimination.  Set
\[
\eta := e - 2\delta = \tfrac12 \log(256/243),
\qquad
\kappa := e - \delta.
\]
Note $\eta > 0$ (elementary: $256 > 243$) and $e/2 > \eta$
(elementary: $3^{9} > 2^{14}$, i.e.\ $19683 > 16384$).

\begin{theorem}[b2d-core-single slice local kill]
\label{thm:p12-b2d-core-single-slice}
Let $2a < T_{0} < c$, $\varepsilon := T_{0} - T$,
$e/2 \le R < d/2$, $R < \sigma < \varepsilon < \varepsilon_{\max}$.
Then for every
\[
x \;\in\; \bigl(R,\ \min\{\sigma,\ d - \sigma,\ R + \eta\}\bigr)
\qquad (\text{slice } C_{19})
\]
one has $h(x) = 0$.
\end{theorem}

\begin{proof}
The proof enumerates $19$ horizon-legal source positions
$u_{1}, \ldots, u_{19}$, computes the raw operator equations
$Q_{i} := L h(u_{i}) = 0$ under the anti-reflected support-
truncated operator, and shows that the resulting
$19 \times 19$ linear system on the visibility values has
non-singular coefficient matrix.  The unique solution is
the zero vector; in particular $h(x) = 0$.

\smallskip
\noindent\emph{Step~1: source positions.}
\[
\begin{aligned}
u_{1} &= b - x, & u_{2} &= b + x, & u_{3} &= a - x, & u_{4} &= T - x, & u_{5} &= T + x,\\
u_{6} &= a + e + x = T - d + x, & u_{7} &= e - x, & u_{8} &= a + e - x, & u_{9} &= d + x,\\
u_{10} &= 3d + x, & u_{11} &= 2d + x, & u_{12} &= 2e - x, & u_{13} &= T - \delta - x,\\
u_{14} &= \delta + x, & u_{15} &= T + e - x, & u_{16} &= d + \delta + x,\\
u_{17} &= a + 2\delta + x, & u_{18} &= 4e - x = T - 2\delta - x,\\
u_{19} &= a + 3e - x = T + \kappa - x.
\end{aligned}
\]
Horizon-legality $0 < u_{i} < T_{0}$ for $i = 1, \ldots, 19$ follows
by direct computation; the two non-trivial cases are
$u_{5} = T + x < T + \sigma < T + \varepsilon = T_{0}$ and
$u_{15}, u_{19}$ which use the further inequality $e - x < R < \sigma
< \varepsilon$ (from K1 below).

\smallskip
\noindent\emph{Step~2: four universal lower-support kills.}
On $C_{19}$:
\begin{itemize}
\item[(K1)] $h(e - x) = 0$: $0 < e - x < R$, since $x > R \ge e/2$.
\item[(K2)] $h(x - \delta) = 0$: $0 < x - \delta < R$, since
  $x < \varepsilon_{\max}$ and $\varepsilon_{\max} - \delta < e/2$,
  elementary via $(10/9)^{2} < 4/3$, i.e.\ $100 < 108$.
\item[(K3)] $h(|x - \kappa|) = 0$: if $x \ge \kappa$, $x - \kappa <
  \varepsilon_{\max} - \delta < e/2 \le R$; if $x < \kappa$,
  $\kappa - x < \kappa - R < R$ since $2R \ge e > \kappa$.
\item[(K4)] $h(x - \eta) = 0$: $0 < x - \eta < R$, using
  $x > R \ge e/2 > \eta$ (elementary: $3^{9} > 2^{14}$) and
  the slice condition $x < R + \eta$.
\end{itemize}

\smallskip
\noindent\emph{Step~3: five universal upper-support kills on $C_{19}$.}
\begin{itemize}
\item[(H1)] $d - x > \sigma$: direct from the slice condition $x < d - \sigma$.
\item[(H2)] $x + \sigma < 2\varepsilon_{\max} < a$: elementary
  $(5/4)^{2} < 2$, i.e.\ $25 < 32$.  Yields $a - x > \sigma$
  and $b - x > \sigma$.
\item[(H3)] $\delta + x > \sigma$: via $x > e/2$ and
  $\delta + e/2 > \varepsilon_{\max}$, elementary $100 < 108$.
\item[(H4)] $2e - x > \sigma$: via $x + \sigma < 2\varepsilon_{\max} <
  2e$, elementary $\log(5/4) < \log(4/3)$ i.e.\ $15 < 16$.
\item[(H5)] $a - 2\delta - x > \sigma$: via
  $x + \sigma < 2\varepsilon_{\max} < a - 2\delta$, where
  $a - 2\delta = \tfrac12 \log(128/81)$.  Elementary
  $(5/4)^{2} < 128/81$, i.e.\ $25/16 < 128/81$, i.e.\
  $2025 < 2048$.
\end{itemize}

\smallskip
\noindent\emph{Step~4: reduced source equations.}  Applying the raw
operator $L h(u) = p[h(u-a) - h(u+a)] + r[h(u-b) - h(u+b)] +
q[h(u-T) - h(u+T)]$ with anti-reflection and the kills of
Steps~2--3, one obtains for each $u_{i}$ a reduced equation
$Q_{i}$ on the visibility set
\[
V := \{2\delta{+}x, d{+}\delta{+}x, \delta{+}x, 3d{+}x, 2d{+}x, d{-}x,
d{+}x, x, b{+}x, a{-}x, a{+}x, e{+}x,
\]
\[
T{-}x, a{+}e{-}x, 2e{-}x, T{+}e{-}x, T{-}\delta{-}x, 3e{-}x, a{-}2\delta{-}x\}
\]
of $19$ live values.  The $19$ equations
$Q_{1}, \ldots, Q_{19}$ are recorded in the audit
\texttt{P12\_ADVERSARIAL\_AUDIT\_A15\_1B2D\_CORE\_SINGLE\_SLICE\_2026-08-22.md}.

\smallskip
\noindent\emph{Step~5: non-singularity.}  Let $M_{19}$ be the
$19 \times 19$ coefficient matrix of $(Q_{1}, \ldots, Q_{19})$ on
$V$.  Then
\[
\det M_{19} \;=\; p^{8}\, r\, (p - q)^{3}\, (p + q)^{3}\,
\bigl(2p^{4} - 3 p^{2} q^{2} - p^{2} r^{2} + q^{4} - q^{2} r^{2}\bigr).
\]
The scalar factor
$F := 2p^{4} - 3 p^{2} q^{2} - p^{2} r^{2} + q^{4} - q^{2} r^{2}$
satisfies $F < 0$ elementary
(Lemma~\ref{lem:p12-b2d-F-neg} below), and the remaining factors
$p, r, (p-q), (p+q)$ are strictly positive.  Hence
$\det M_{19} \ne 0$, and the homogeneous system $M_{19} v = 0$
forces $v = 0$.  In particular $h(x) = 0$.
\end{proof}

\begin{lemma}[Elementary $F < 0$]
\label{lem:p12-b2d-F-neg}
$F := 2p^{4} - 3 p^{2} q^{2} - p^{2} r^{2} + q^{4} - q^{2} r^{2} < 0$.
\end{lemma}

\begin{proof}
Set $B := (q/p)^{2} = 2^{-3/2}$ and $\theta := (r/p)^{2}
= (\log 3 / \log 2)(2/3)^{3/2}$.  Then
$F / p^{4} = (2 - 3B + B^{2}) - (1 + B)\theta$, and
$$\frac{2 - 3B + B^{2}}{1 + B} < \frac{4}{5} < \theta,$$
whence $F/p^{4} < 0$.  The left inequality is equivalent to
$53 < 38\sqrt{2}$, whose square is $2809 < 2888$.  The right
inequality: $\theta > (3/2)(2/3)^{3/2} = \sqrt{2/3} > 4/5$, via
$\log 3/\log 2 > 3/2$ (elementary: $9 > 8$) and $50 > 48$.
\end{proof}

\begin{remark}[The genuine visibility wall at $x = R + \eta$]
\label{rem:p12-b2d-eta-wall}
The slice condition $x < R + \eta$ is the tight one.  For
$x > R + \eta$, the value $h(x - \eta)$ becomes live (i.e.\
$x - \eta > R$), a new visibility direction opens, and the
$19 \times 19$ system is no longer the correct closed system.
\end{remark}

\subsection{Scope: what is and is not proven}

\begin{itemize}
\item \textbf{Proven $\checkmark[M]$:}
  Theorem~\ref{thm:p12-b2d-core-single-slice} (b2d-core-single
  slice $C_{19}$) plus Corollary~\ref{cor:p12-b2d-upper-local}
  (b2d-upper local kill in the b2c module).
\item \textbf{Open:}
  \begin{enumerate}
  \item[(i)] Rest of b2d-core-single beyond $x = R + \eta$
    (new visibility beyond the wall).
  \item[(ii)] b2d-core-both entirely.
  \item[(iii)] Consequently, full b2d
    (Open Problem~\ref{open:p12-subwedgeA-open}).
  \end{enumerate}
\end{itemize}

\begin{remark}[Parameter wedge with slice = full defect]
\label{rem:p12-b2d-parameter-wedge}
For $(R, \sigma)$ satisfying
$\sigma \le \min\{d - \sigma, R + \eta\}$, i.e.\
$\sigma \le d/2$ \emph{and} $\sigma \le R + \eta$, the slice
$C_{19}$ covers the entire defect strip $(R, \sigma)$.  Whether
subsequent propagation legally closes b2d on this parameter wedge
is the natural next investigation and is not established here.
\end{remark}
